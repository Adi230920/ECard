Use TypeScript with clear, readable, maintainable code. 
Prefer small reusable components and single-purpose functions. 
Keep UI, database, OCR, parsing, and utility logic separated. 
Avoid unnecessary dependencies and abstractions. 
Use descriptive names and consistent folder structure. 
Handle errors explicitly and provide useful user feedback. 
Never hardcode sensitive information or introduce paid services. 
Do not rewrite working code unnecessarily. 
Before adding a library, confirm that an existing dependency cannot solve the requirement. 
Keep comments limited to explaining genuinely non-obvious logic. 
Prioritize reliability and simplicity over clever implementations. 
Follow the existing project structure and specifications unless explicitly instructed otherwise.
